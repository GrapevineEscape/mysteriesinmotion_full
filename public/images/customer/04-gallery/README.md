# 04-gallery — Live show detail pages

Shared on every live show’s “From the evening” gallery (until per-show galleries exist).

| Filename | What it should be |
|---|---|
| `scene-1.jpg` | Cast / venue mid-scene |
| `scene-2.jpg` | Guests interacting with actors or clues |
| `scene-3.jpg` | Celebration / reveal energy |

Prefer **three different** moments — not the same photo reused.
